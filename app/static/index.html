实际付款账本
仅登记你已在淘宝完成的付款。更新券余额并排除已买商品，剩余报价必须重采。
本地自动备份
每次写入前保留上一份项目，最多20份；不包含浏览器登录态。恢复后仍需核对现实中的付款和券余额。
退款情景核算（不自动退款）
只比较已知费用。填写退款页面给出的现金退款额，不填凑单品标价；尚未确认的退款不计入确定性最优路径。
项目 JSON
可修改完整规则和报价。金额使用整数“分”。修改账号、地址、支付方式、商品或权益后，旧报价会因指纹不符自动失效。
使用边界
本版有可运行的优化内核、规则模拟、历史清单和授权适配器；没有淘宝实账号端到端验收。浏览器总额采集不能自动证明优惠资源独立。App专属券、直播间入口和某些活动可能在网页不可用。
退凑单收益不纳入确定性推荐：未核实退款分摊、回收与运费前，不把退款当作确定返现。可选凑单商品按全部保留、全部付费计入。
数据默认仅存本机 .data；不调用大模型、不上传Cookie。独立浏览器profile含登录态，应当按敏感文件保护。源码、调研及测试说明在安装包 docs 中。
