# v0.5.0：店铺与组合优惠、购物车分组导入

## 普通用户入口

首页新增「从淘宝购物车导入」和「店铺与组合优惠」。原有简单主页、真实结算报价和一键体验保留。
新页面为 `/shopping-tools`：导入购物车 → 补充优惠 → 看省钱方案。右上角「一键体验」自动准备
四件虚构商品、分组、店铺券、多件折扣、搭配券及跨店券。示例估算为560元，仅供流程测试；不访问
淘宝，不修改当前项目。购物车体验与真实账号明确区分，示例不能导入真实清单。

## 这次增加的规则

- 店铺/指定商品范围、排除商品，参与凑门槛的商品与实际获得优惠的商品可以不同。
- 必须同时购买的商品和数量；满件、至少几种SKU、每满减、折扣封顶、多档满减。
- 指定组合一口价：明确每种商品的精确数量。多套、额外数量或拆数量不猜，需单独建行和核价。
- 同一组店铺优惠自动择优；支持整笔互斥或重叠商品互斥。规则阶段、门槛基数、入口和有效期独立。
- 同一物理券的余额共用。已用券后自动切换其他优惠的条件进入付款顺序搜索，不把替代优惠当成
  初始状态可随意使用的价格。大量余额情景和候选组合有预算上限，截断会明确报告。
- 每一笔输出采用的优惠和分摊明细；解释接口能说明指定组中未用券的原因。

默认店铺表单给出互斥择优提示，但不是所有活动都能套同一规则。旧项目不自动改写；新增优惠必须
核对券详情后确认。只看到「满X减Y」文案，不自动推断可用商品、叠加、库存或个人领券资格。
购物车券后展示价不倒推成原价，也不再次扣券。规则估算和真实结算始终分开。

## 浏览器与分组支持边界

本机启动独立Chrome/Edge资料目录（找不到时尝试已安装的Playwright Chromium），由本人扫码登录。
只读取页面当前已经渲染的商品信息，不调用淘宝私有接口，不导出Cookie，不处理验证码，不提交订单、
支付或退款。登录资料会由浏览器留存在本机独立目录，应当按敏感数据保护。

自动读取保留部署方平台许可声明：环境变量 `TAOBAO_PLATFORM_PERMISSION_REFERENCE`，或连接设置中的
许可引用和明确确认。该声明不等于官方授权验证，也不能用任意文字冒充取得许可。浏览器启动需
本机安装Chrome/Edge；源码版另需安装 `requirements-browser.txt`。

读取保留商品行标识、规格、数量、店铺、可确认口径的展示金额及分组来源。仅有明确分组标签和
稳定标识的页面允许自动切换淘宝分组。未识别原生分组时，可本人在网页切换后读取当前页面；
按店铺筛选会另标识，不当成淘宝自定义分组。App独有、网页没有展示的分组无法凭空读取。

默认含旧版购物车选择器及显式属性适配，**尚未取得真实账号页面验收，不能保证当前淘宝页面即插即用**。
不匹配时明确报错；可在高级页面校准，不能把识别失败说成空购物车。仅读取当前加载行，未完成全量
分页/虚拟滚动采集。每次查看最多500行；单次优化计划最多28行，超限报错而非静默截断。

选择分组后只导入勾选的商品；缺少数量、重复行、过期快照、账号/清单版本不一致会停止。
失败读取会废弃前一份快照。换账号须断开后声明换号，当前版本不自动识别淘宝账号主体。
相同来源行可幂等导入，数量变化必须重新核对金额；不会覆盖已付款商品。

## 尚未交付的能力

真实淘宝账号端到端验收、全部私人券包自动读取、所有直播间/App专属权益、跨版本原生分组适配、
SKU数量自动拆单，以及未核实凑单退款收益，均不应当被描述为已支持。此版没有改变Mac签名/公证状态。

## 验证与复现

本地可用核心/API测试集167项通过，其中45项为本次规则和购物车回归；该本地基线不包含远端全部
桌面发布测试，完整仓库测试以对应提交的GitHub Actions为准。另17项Chromium页面/DOM夹具测试通过，
JavaScript页面异常0。页面测试使用内存页面与FastAPI桥接，购物车DOM为人工合成，不是真实淘宝抓取。

```bash
python -m pytest -q
node --check app/static/shopping.js
node --check app/static/cart-reader.js
# 先安装requirements-browser.txt；按本机情况设置已有Chromium的绝对路径
TBPC_TEST_CHROMIUM=/usr/bin/chromium PYTHONPATH=. python scripts/check_shopping_ui.py
```

规则测试涵盖店铺隔离、指定商品/排除商品、必选搭配数量、种类与件数、多档满减、套餐多套防低估、
店铺优惠择优、跨层门槛、券耗尽后的条件报价、单品定金、整数分摊和未知价格拒算。购物车测试涵盖
来源分组、选择导入、重复/失效行、数量更新、限额、接口令牌/跨站、版本冲突和演示不改真实数据。
