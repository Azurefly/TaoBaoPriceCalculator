# 购物车分组切换补充校验

切换标签后，网页可能继续显示上一个分组的商品。不能仅因标签名称已经变化，就把旧列表归入新分组。

现在在自动切换后要求：目标标签已激活、商品行内容相对原列表已变化、没有可识别的加载中标记或读取错误，
且连续三次观察的行标识/规格/数量稳定。超时停止，不导入旧列表。两个分组恰好含相同商品时会保守停止，
由用户在网页确认并点击当前页读取。该检查减少异步错组风险，但不构成真实淘宝适配和全量采集的证明。

新增4项回归：标签变化不改变行签名、等待加载完成与列表稳定、旧列表不得成功、错误后重新累计稳定状态。
本地可用核心/API测试集从167增至171项（本次总计49项新回归），17项页面/合成DOM测试再次通过。
完整仓库、原生安装包的检查结果以对应提交CI为准；没有使用真实淘宝账号或私人购物记录。
