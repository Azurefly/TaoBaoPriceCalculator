# v0.4.0 简单模式与一键体验

默认首页只保留三步：**选商品 → 核对价格 → 看付款方案**。

## 第一次使用

直接点 **一键体验**。程序在内存里创建虚构示例、计算三种付款方式，自动显示两笔付款步骤。
不需要登录、不需要上传文件、不需要选模式或配置优惠规则。体验中的“模拟完成这一笔”只改变页面，
不创建订单、不记真实付款、不扣券、不写项目或备份。退出后重新读取原有真实清单。
高级界面的演示按钮也跳转到同一入口，不再用示例替换真实项目。

## 用自己的订单

1. **添加商品**：名称必填，参考展示价可空。规格、数量、定金收起为选填项。
2. **核对价格**：在淘宝选好一组商品，进入确认订单页但不提交；记录仍需支付金额和实际使用的券/红包。
   先记全部一起买，再记几组分开买，比较才充分。只按实际金额比，不在参考展示价上重复减券。
3. **查看方案**：一次比较逐件、合并、自由组合，显示应付金额、分几笔、每笔商品和优惠。
   自行在淘宝付款后，再点“我已在淘宝付完这一笔”。金额、优惠变化需明确确认；随后重新核对剩余价格。

没有真实报价、价格过期或共享券冲突时，只给下一步操作，不编造最低价、节省金额或自动采价能力。
金币、购物金、返券等复杂记录请在 **更多 → 高级设置与旧版界面** 中处理。全部高级功能仍在 `/advanced`。
当前没有实现登录后全自动读取淘宝全部优惠，不能用简化界面掩盖这个限制。

## 实现与验证

- 新默认页面：`app/static/index.html`、`simple.css`、`simple.js`。
- 简单 API：`app/simple.py`；真实清单只接受严格真实报价，演示独立在内存计算。
- `tests/test_simple.py`：演示隔离、重复体验、真实金额、定金、防跨站、版本变化、语法检查。
- `scripts/check_simple_ui.py`：Chromium + 实际 FastAPI TestClient 桥接，无淘宝访问。
- 桌面打包烟雾测试新增：真实点击“一键体验”，校验示例 1202 元，并比较体验前后项目未变。
- 本地浏览器测试覆盖新增商品、报价确认、模拟步骤、退出恢复、付款确认、XSS、390px布局。

不会因此承诺修复 Gatekeeper 安装拦截。
